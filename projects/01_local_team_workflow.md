# Project 1 — A small team's Git workflow

**Goal:** Demonstrate trustworthy local collaboration with no network access.

1. Create a working repository and a separate bare remote.
2. Commit a small README and working code; push main.
3. Create `feature/validation`, implement and test one change, and push.
4. Simulate a second collaborator using a second clone from the bare remote.
5. Integrate the feature with a deliberate merge strategy.
6. Create and resolve one conflicting edit intentionally.
7. Inspect `git log --graph --all --oneline` and describe both histories.

**Deliverables:** command transcript, clear commit messages, test evidence, conflict-resolution explanation, and a clean status.

**Checks:** working commits are reachable from the remote; no unresolved conflicts; no credentials or build output committed.
