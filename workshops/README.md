# Six guided Git & GitHub workshops

These workshops turn the 36 guided lessons and 24 graded Git labs into real developer decision-making practice. They use **only the disposable local fixtures** generated by the course tools, except for optional conceptual review of GitHub features. Workshops are intentionally not autograded: each asks for reasoning, evidence and a short technical write-up.

## Workshop submission

For each workshop include (1) the task IDs that passed, (2) the **predicted** Git state before applying commands, (3) command outputs or a minimal commit graph, (4) the failure you encountered or a deliberate negative example, (5) a safe recovery path, and (6) a short summary of what you would do differently in a shared repository.

These exercises do not grant a hosted credential, production release authority or a GitHub certification. See the [final assessment](../ASSESSMENT.md) for scoring and safety gates.
